      Using Claude as a Learning Partner

      Build a consistent learning habit with a Claude agent that prepares daily concepts and practice tasks.

      Published
      Nov 3, 2026
      Reading time
      3 minutes
      Topics
      AI, Learning, Claude

      On this page

      1. Setting up the workspace
      2. Creating the agent
      3. Moving it to the cloud

      Learning and adapting have always been crucial parts of software engineering. With AI tools, learning can become much easier and more interesting, too.

      I thought I’d brush up on my Docker skills to refresh my memory, since I hadn’t run Docker commands manually recently (thanks to agents :P). So I wondered how I could use Claude as a learning partner. I wanted a consistent, ongoing learning experience and not just a one-off “teach me Docker” session.

      So I built a Claude agent to act as a learning partner. It would prepare a set of concepts and tasks for me to learn and practice, every day at 8:00 a.m., so I could learn a little at a time.

      Setting up the workspace

      First, I created a folder on my local drive (for example, docker-learning).

      Then, in Claude Desktop, I went to the Code tab and created a new chat. From the “Choose environment” menu, I selected the folder I’d created. It opened as a new workspace.

      Creating the agent

      After that, I created the agent by sending this prompt:

      I want to use this workspace as a learning space to learn Docker. I want to practice Docker commands and theories daily. Set up an agent and create a routine to give me Docker tasks to perform every day at 8:00 a.m.

      With this prompt, Claude set up the CLAUDE.md file with instructions, created an agent inside the workspace, added a progress file, and scheduled a routine.

      docker-learning
      docker-learning/
├── CLAUDE.md            # instructions for the workspace
├── Progress.md          # tracks what I've covered
└── .claude/
    └── agents/
        └── docker-coach.md

      You can find the routine in the Scheduled tab in Claude Desktop, and invoke the agent any time with @docker-coach.md. We can fine-tune any of this by asking Claude to update the agent. For example: Update the agent to include reference links for each theory.

      Moving it to the cloud

      We can take this a step further by moving the workspace to a cloud session. Just create a GitHub repository and connect it to Claude. If you have the GitHub CLI installed, you can ask Claude to create the repository and move the session for you.

      Once the session is in the cloud, your laptop doesn’t need to stay awake. Claude runs the routines there, and you can check them in the Claude mobile app.

      As you can see, learning has never been easier. We can follow a similar approach to learn any topic and, more importantly, do so consistently.
